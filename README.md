# 🛒 쇼핑 리스트 앱

간단하고 사용하기 편한 쇼핑 리스트 웹 앱입니다.

## 기능

- ✅ 쇼핑 아이템 추가
- ✅ 아이템 완료 여부 체크
- ✅ 아이템 삭제
- ✅ 로컬 스토리지를 이용한 데이터 저장
- ✅ 통계 표시 (전체, 완료, 남은 항목)
- ✅ 반응형 디자인
- ✅ 접근성(Accessibility) 지원

## 사용 방법

1. `shopping-list.html` 파일을 웹 브라우저에서 열기
2. 새로운 아이템을 입력하고 "추가" 버튼 클릭 또는 Enter 키 입력
3. 완료한 아이템은 체크박스를 클릭하여 표시
4. 삭제할 아이템의 "삭제" 버튼 클릭

## 기술

- HTML5
- CSS3 (Grid, Flexbox, Animation)
- Vanilla JavaScript
- LocalStorage API

## 특징

- 아이템은 브라우저의 로컬 스토리지에 저장되어 페이지를 새로고침해도 데이터가 유지됩니다.
- WAI-ARIA 표준을 준수하여 스크린 리더와 키보드 네비게이션을 지원합니다.
- 현대적이고 사용자 친화적인 UI 디자인
